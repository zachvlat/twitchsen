twitchsen

A minimal, self-hosted web application for watching Twitch streams without tracking or bloat.

GPL-3.0 License • Docker • Node.js

Why twitchsen?

twitchsen provides a clean, distraction-free viewing experience. It bypasses the heavy Twitch website and ads, delivering just the video stream and chat.

  • No Tracking: No Twitch page, no analytics scripts.
  • Self-Hosted: Run it on your own server with Docker.
  • Lightweight: Pure HTML, CSS, and Vanilla JS (no frameworks).
  • Customizable: 6 built-in themes + custom CSS editor.
  • Mobile Friendly: Responsive design for all devices.

How It Works

Stream Relay

The backend resolves the channel's HLS playlist using streamlink. The browser plays it via hls.js. This relays segments through your server, bypassing CDN blocks.

Read-Only Chat

Connects to Twitch IRC over WebSocket for an anonymous, read-only chat experience. Supports Twitch, 7TV, BTTV, and FrankerFaceZ emotes.

Persistence

Follows and custom themes are stored server-side in SQLite (using Node's built-in node:sqlite), so no native modules are needed.

Live Status

Live/offline status is fetched from api.ivr.fi (can be disabled in config).

Quick Start (Docker)

The easiest way to run twitchsen is via Docker. This command starts the service on port 4444.

docker run -d \
  --name twitchsen \
  --restart unless-stopped \
  -p 4444:4444 \
  -v ~/twitchsen/data:/app/backend/db \
  zatsando/twitchsen:latest

Then open http://localhost:4444 in your browser.

Note: The -v volume mounts your local data directory to the container. This ensures your follows and themes persist across updates. Without it, data is lost when the container is replaced.

Running Without Docker

If you prefer not to use Docker, you need Node.js 22.13+ and streamlink installed on your system.

cd backend
npm install
node server.js
